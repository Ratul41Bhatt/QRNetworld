Payment callback integration

1. Announce a payment on a device

Post a payment to the QRNet gateway and it does the rest: it looks up the terminal ID, finds the soundbox mapped to it, and publishes the announcement over MQTT so the device speaks the amount.

POST https://qrnet-gateway.local/api/payment

Request body (JSON)

Field Type Required What it does
tid String Yes Terminal ID registered under Device Inventory.
amount Number / String Yes Payment amount. The device reads this aloud.
invoice String No Invoice reference, shown on the device screen.
rrn String No Retrieval reference number, kept for reconciliation.
card_number String No Masked card or account number, stored in the payment log.

Code samples

cURL 
curl -X POST https://qrnet-gateway.local/api/payment \
  -H "Content-Type: application/json" \
  -d '{
    "tid": "20501603",
    "amount": 250.50,
    "invoice": "402940",
    "rrn": "392040590390",
    "card_number": "1234-xxxx-xxxx-9012"
  }'
JavaScript (fetch) 
const payload = {
  tid: "20501603",
  amount: 250.50,
  invoice: "402940",
  rrn: "392040590390",
  card_number: "1234-xxxx-xxxx-9012"
};

fetch('https://qrnet-gateway.local/api/payment', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(payload)
})
.then(res => res.json())
.then(data => console.log('Announcement sent:', data))
.catch(err => console.error('Request failed:', err));
Python (requests) 
import requests

url = "https://qrnet-gateway.local/api/payment"
payload = {
    "tid": "20501603",
    "amount": 250.50,
    "invoice": "402940",
    "rrn": "392040590390",
    "card_number": "1234-xxxx-xxxx-9012"
}

headers = {"Content-Type": "application/json"}
response = requests.post(url, json=payload, headers=headers)
print("Status code:", response.status_code)
print("Response:", response.json())
